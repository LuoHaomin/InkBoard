# 墨板 InkBoard — 把电纸书当电脑手写板

通过 WiFi/USB adb 读取电纸书的笔输入事件流，把设备变成电脑的手写板（白板模式）
或数位板（鼠标模式）。笔画全程矢量处理：压感曲线、平滑、切割橡皮、多页、会话持久化。

## 已实测设备

| 设备 | 数位板 | 坐标 | 压感 | 备注 |
|---|---|---|---|---|
| 汉王 N10 Plus | pen_touch | 1872×1404 | 1024 (10bit) | 笔尾=橡皮 |
| Bigme inknote X color | Wacom EMR | 2480×1860 | 4095 (12bit) | 悬停上报；笔侧键=橡皮 |

其余开启"USB/无线调试"且笔走标准 Linux input 子系统的电纸书理论上均可用
（自动探测输入节点与量程）。

## 原理

`adb shell getevent -lt <节点>` 把设备的笔事件流转发到电脑：坐标、压感、按键状态
随 `SYN_REPORT` 成批上报（~200-300Hz）。电脑端解析后经过 Lorien 式采样管线
（死区 → 贝塞尔稳定器 → 速度变细 → 压感限速 → 点优化器）绘制到 pygame 窗口；
橡皮是对象级操作（切割/圈选），全部可撤销；矢量 JSON 自动保存，支持 PNG/SVG 导出。

## 使用

```bash
# 1. 设备开启调试（USB 调试或无线调试），无线需先配对连接:
adb pair <设备IP>:<配对端口>
adb connect <设备IP>:<端口>

# 2. 启动（uv 管理 Python 环境）
uv run python main.py        # 白板模式
uv run python mousepad.py    # 鼠标模式
# 或直接运行打包好的 InkBoard.app 选择模式
```

- 笔尖书写，压感映射笔迹粗细；有笔尾橡皮的设备**笔尾即橡皮**，无笔尾橡皮的设备
  （如 Bigme）**按住笔侧键即橡皮**
- **圈选擦除**：橡皮状态下画闭合圈（缺口 < 圈直径 30%），圈内整笔删除；不闭合则按
  切割橡皮（扫过的笔画断开，只删扫到的部分）
- **笔迹平滑** `M`（关/轻/中/强）；**压感曲线** `P`（柔软/适中/硬笔/自定义，`U` 打开
  可拖拽控制点的曲线编辑器）；粗细倍率 `[` `]`（最细）`-` `=`（最粗）
- **多页**：`←→`/`PgUpPgDn` 翻页（末页续翻自动开新页），`N` 插入新页
- **会话自动保存**：矢量 JSON 存于 `~/.hanwang-tablet/autosave.json`，换设备打开
  自动按量程重缩放；`S` 存 PNG、`X` 导出 SVG（当前页）
- 连接期间自动保持设备唤醒（`--no-keep-awake` 关闭）
- 建议关闭设备自动锁屏；鼠标模式需在系统设置→辅助功能中授权

## 导出电纸书自带笔记

```bash
uv run python export_notes.py
```

把汉王设备 `/sdcard/notes` 里的手写笔记批量导出到桌面（PNG + 矢量 SVG）。
`.psl` 笔迹格式已完整逆向（`NPSL0001`，大端 float32 点序列），首次运行拉取缓存
（~44MB 存于 `~/.hanwang-tablet/notes-cache`），重复运行直接用缓存；
`--min-stroke` 控制草稿过滤，`--png-only` 只导位图。

## 参数

```
--serial         指定 adb 设备（默认自动探测带笔输入的设备）
--width          窗口宽度，默认 1123
--rotation       设备摆放旋转角 0/90/180/270（横/竖拿）
--min-pressure   压感下限（默认 50，按设备量程归一化）
--pen-size       基准笔宽，默认 6
--curve          压感曲线预设
--smooth         平滑级别
--no-keep-awake  不阻止设备息屏
```

## 快捷键

`Z` 撤销 · `Shift+Z` 重做 · `C` 清空当前页 · `S` 保存 PNG · `X` 导出 SVG ·
`E` 橡皮/画笔 · `1-4` 颜色 · `R` 旋转 · `P` 曲线 · `M` 平滑 · `←→` 翻页 · `N` 新页 ·
`[` `]` `-` `=` 粗细
